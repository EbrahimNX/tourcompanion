# Tour Companion

A mobile-first PWA guide script app for tour leader Ebrahim — Sharm el-Sheikh, Egypt.

## Features

- **6 complete tour scripts**: Cairo Day Trip, Sharm City Tour, Ras Mohamed, Desert Safari, Nabq Mini Safari, Magic Dahab
- **Nationality briefings**: Romanian, Polish, Czech, Portuguese — cultural notes, phrases, common questions, surprise facts
- **Offline capable**: Works without internet once installed
- **Android installable**: Add to Home Screen from Chrome

## Install on Android

1. Open Chrome on your phone
2. Go to: `https://[your-github-username].github.io/tourcompanion`
3. Tap the three-dot menu → **Add to Home Screen**
4. Tap **Install**

The app icon will appear on your home screen and works fully offline.
